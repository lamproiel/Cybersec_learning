ip addr

ip route get <ip>
ip neigh
ip -6 neigh
ip rule
ip route show table all
ss -tulpen
sudo conntrack -L
sudo nft list ruleset
sudo iptables -S

traceroute <ip>
mtr <ip>
dig <domain>```

tcpdump:```
sudo tcpdump -ni any
sudo tcpdump -ni eth0 arp
sudo tcpdump -ni eth0 icmp6
sudo tcpdump -ni any tcp port 80 or tcp port 443
sudo tcpdump -ni any udp port 53 or tcp port 53```

tshark и wireshark:```
capinfos traffic.pcapng
tshark -r traffic.pcapng -q -z io,phs
tshark -r traffic.pcapng -q -z endpoints,ip
tshark -r traffic.pcapng -q -z conv,ip
tshark -r traffic.pcapng -q -z conv,tcp```
