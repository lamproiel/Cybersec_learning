
динамическая память - это когда можно занять оперативную память пк на определенное время, можно поработать с ней, а позже очистить (освободить эту память).
	т.е. можно выделить память, записать туда какое-то значение, а позже, когда эти данные уже не нужны, можно будет очистить память.

```cpp
int num = 10;  //под эту переменную в оперативке было выделено 4 байта, и это место будет освобождено тогда, когда программа завершит работу.
```

также можно создавать эти вещи с учетом динамической памяти
	(для обычной переменной использовать динамическую память неразумно, т.к. она занимает мало места, для этого можно использовать массивы)

```cpp
int *nums = new int[3];  //каждый элемент - одна переменная (массив занимает 12 байт)
``` 
- `*nums` создание указателя (выделение памяти работает конкретно с указателями)
- за счет  `new` выполняется процесс выделения памяти
- `new int[3];` под что выделяется память (под некий массив)
в итоге получилось, то что мы внутрь указателя выделили память под 3 элемента.

теперь можно обратиться к `nums` (как будто это массив), обратится к элементу по индексу 0, установить туда некое значение, также обратиться к другим элементам, и вывести этот элемент на экран.
```cpp
int *nums = new int[3];  //выделение памяти (если выделили, то надо в ручном режиме очищать, когда массив больше уже не нужен)
nums[0] = 45;
cout << nums[0] << endl;
delete[] nums;  //очищение памяти (если была бы обычная переменная, то тогда [] не понадобились бы)
```
- получился динамический массив
