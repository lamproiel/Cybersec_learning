## калькулятор с if, else, else if
```cpp
#include <iostream>

int main() {
setlocale (LC_ALL, "RU");

float num1, num2, res;
std::cout << "Enter num1: ";
std::cin >> num1;

std::cout << "Enter num2: ";
std::cin >> num2;

// +, -, *, /

char math;
std::cout << "Enter math symbol: ";
std::cin >> math;

if(math == '+')
	res = num1 + num2;

else if (math == '-')
	res = num1 - num2;

else if (math == '*')
	res = num1 * num2;

else if (math == '/')
	res = num1 / num2;
	
std::cout << "Result: " << res << std::endl;

return 0;
}
```

## другие математические операции

 кроме стандартных мат. операций есть следующие

### остаток при делении
`res = num1 % num2;` получаем остаток при делении одного числа на другое;
при float нельзя

```cpp
int a = 10, b = 3, z;
z = a % b;
std::cout << z;
```

### сокращенные операции

вместо
```cpp
a = a + 5; //либо +, -, и т.д.
```
можно:
```cpp
a /= 5; //либо -=, +=, *=
```
	означает то что то знание, что было в переменной a, мы разделим на число 5, и новое значение запишем обратно в переменную

также можно:
```cpp
a++; //к переменной добавляем единицу
a--; //от значения переменной отнимаем единицу
```

## пространство имен, декларация

пространство `std` можно задекларировать в начале файла, т.е. можно записать и в след. раз не прописывать повторно 

```cpp
using namespace std;
```
	это значит то, что теперь внутри файла можно использовать по умолчанию это пространство имен, именно поэтому повсюду `std` можно не прописывать. т.е.:

```cpp
#include <iostream>

using namespace std;

int main() {
setlocale (LC_ALL, "RU");

float num1, num2, res;
cout << "Enter num1: ";
cin >> num1;

cout << "Enter num2: ";
cin >> num2;

char math;
cout << "Enter math symbol: ";
cin >> math;

if(math == '+')
	res = num1 + num2;

else if (math == '-')
	res = num1 - num2;

else if (math == '*')
	res = num1 * num2;

else if (math == '/')
	res = num1 / num2;
	
cout << "Result: " << res << endl;

return 0;
}
```

## создание случайных чисел

для создания случайного числа используется функция:
	`rand();` она возвращает случайное число в диапазоне от 0 до 1

чтобы указать свой собственный диапазон надо изначально к числу 1 добавить фунцию rand, а также вконце прописать % на какое либо число
`1 + rand() % 20;` случайное число от 1 до 20

```cpp
int result = 1 + rand() % 20;
std::cout << result;
```
при запуске будет выводиться случайное число в этом диапазоне, но при каждом запуске программы оно будет одним и тем же,
	чтобы это исправить, надо дописать функцию
```cpp
using namespace std;
srand(time(NULL)); //нет зависимости от времени, и каждый раз будет запускаться случайное число в диапазоне
int result = 1 + rand() % 20;
cout << result << endl;
```
если программа выдаст ошибку, то надо указать где была описана функция time 
	`include <time.h>` с, старый вариант
	`include <ctime>` с++, более современный вариант
	подключение директивы, поддержка функции `time`.
