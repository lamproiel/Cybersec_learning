# урок 1

```cpp
#include <iostream>

int main() {
	// comment
	
	/*
	comment 
	comment
	*/
	
	setlocale(LC_ALL, "RU");

    std::cout << "hello world!\n" << std::endl;
    std::cout << "Привет!";
    
    return 0;
}
```

- `#include <iostream>`
	- `#include` — директива препроцессора.
		- Она подключает заголовочный файл в программу.
	- `<iostream>` содержит средства стандартного ввода-вывода:
	    `std::cout`, `std::cin`, `std::cerr`.

- `int main() {}`
	- `main` — точка входа в программу.
		- Выполнение программы начинается с функции `main`.
	- `int` означает, что функция возвращает целое число.

- `// комментарий`
	- Однострочный комментарий.
	- Всё после `//` до конца строки игнорируется компилятором.

- `/* комментарий */`
	- Многострочный комментарий.
	- Текст между `/*` и `*/` игнорируется компилятором.

- `std::cout`
	- `std` — стандартное пространство имён.
	- `::` — оператор разрешения области видимости.
	- `cout` — объект стандартного потока вывода.

- `std::cout << "Hello\n";`
	- `<<` передаёт строку в поток вывода.
	- `\n` переводит курсор на новую строку.
	- `;` завершает выражение.

- `std::endl`
	- Переводит строку.
	- Дополнительно принудительно очищает буфер вывода.
	- Для обычного вывода чаще используют `\n`.

- `return 0;`
	- Завершает функцию `main`.
	- Код `0` обычно означает успешное выполнение программы.
