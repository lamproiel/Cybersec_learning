
функции - небольшие подпрограммы, которые можно самостоятельно описывать, в эти подпрограммы можно выносить некий повторяющийся код и далее каждый раз когда необходимо будет выполнить этот код, то можно будет обратиться к функции,  и весь этот код будет выполняться.
	т.е. функции служат для очистки кода, ведь в них можно выносить весь повторяющийся код и каждый раз, когда его нужно будет выполнить, то просто обратиться к ним.

# встроенные функции

функция `main` - основная функция, с которой вообще у нас вся программа запускается.
```cpp
int main() {
}
```

`setlocale` - встроенная функция, мы ее вызываем, и к нашей программе устанавливается кодировка.
	т.е. в файле (библиотеке iostream) есть описание такой функции как setlocale, в этой функции есть строчки кода, за счет которых добавляется кодировка к самому проекту, и далее мы просто вызываем эту функцию, передаем туда какие-то определенные параметры, и после этого функция выполняется.
```cpp
setlocale (LC_ALL, "RU"); 
```

# создание своих функций

все функции должны находиться вне других функций, т.е. вне функции `main`, а над ней, иначе она будет невидимой внутри функции `main`.

1.  надо указать возвращаемый тип данных
	если функция ничего не возвращает, то прописываем:
```cpp
void  //тип данных
```

2. далее, после этого типа данных, надо указать название для функции (любое).
```cpp
void print()  //в () можно принимать какие-то параметры
```

3. далее открываются фигурные скобки (ДОЛЖНЫ ОТКРЫВАТЬСЯ ВСЕГДА)
```cpp
using namespace std;

void print() {
	cout << "Hello" << endl; // внутри {} находится тот код, который всегда будет выполняться при вызове функции
}
```

4. далее нужно вызвать функцию в ручном режиме 
```cpp
using namespace std;

void print() {
	cout << "Hello" << endl;
}

int main() {  //программа запускается из функции main
	setlocale(LC_ALL, "RU");  //кодировка

	print();  //вызываем функцию print, она обращается к функции и выполняет код внутри функции.  () остаются пустыми, т.к. мы не принимаем никаких параметров
	
	return 0;
}
```

удобство функций в том, что можно вызвать функцию много раз.

# значения внутри функции

чтобы передать некое значение в функцию, необходимо при создании функции описать параметры.
```cpp
using namespace std;

void print(string word) {  //функция принимает параметр string с названием word, т.е. эта функция принимает 1 параметр
	cout << word << endl;
}

int main() {
	setlocale(LC_ALL, "RU");

//3 раза вызываем функцию 
	print("Hello");  //и передаем этот 1 параметр
	string words = "World";  //отдельная переменная 
	print(words);
	print("!!!"); 
	
	print("some");  // cout << "" << endl;
	//функция для вывода некой информации.

	return 0;
}
```

# функции, которые будут возвращать некое значение

функция `main` возвращает значение (число 0), означает что программа завершилась корректно.

для остальных функций, что будем прописывать, возвращать что-либо не обязательно, если это не нужно.

функция `add` будет складывать числа, а также результат будет возвращаться обратно, и этот результат можно поместить в некую переменную.

```cpp
using spacename std;

int add(int a, int b) {  //указываем тип возвращаемого значения int.
	return a + b;  //возвращаем из функции сложение параметров
}

int main() {

	int res1 = add(5, 7);  //за счет этой функции мы выполним сложение чисел, и дальше результат будет возвращен и этот результат можно будет поместить в некую переменную.
	int res2 = add(51, 7); 
	// это удобно тем, что с результатом можно будет работать.
	if (res1 > res2)
		cout << res1;
	else 
		cout << res2;

	return 0;
}
```

# скелеты функций

до этого все функции описываются до функции `main`, и если их вырезать и вставить под функцию `main`, то в таком случае при запуске проекта будет возникать ошибка.
	ошибка будет возникать, т.к. программа читает код сверху вниз, т.е. она доходит до функции `main` , затем доходит до вызова функции `add` и не понимает, где функции были прописаны, т.к. до этой строки функции не фигурировали.

удобнее, когда функции описаны внизу, и чтобы их описать, то нужно прописать скелеты функций.
	сначало все функции переносятся вниз.
```cpp
using namespace std;
 
int add(int a, int b);  //описывается скелет функции

int main() {

	int res1 = add(5, 7);
	int res2 = add(51, 7); 
	if (res1 > res2)
		cout << res1;
	else 
		cout << res2;

	return 0;
}

int add(int a, int b) {
	return a + b;
}
// теперь функции в компактном формате описаны вверху, а полноценное описание находится снизу, под основной функцией.

```
