
## Что делает ARP
- ARP нужен для соответствия:
  - IP адрес → MAC адрес в рамках одной L2-сети (локалки).
- Если хост хочет отправить кадр на IP получателя:
  1) Смотрит: в своей таблице ARP есть MAC для dst IP?
  2) Если нет — шлёт ARP request в broadcast.
  3) Хост с нужным IP отвечает ARP reply.

## ARP request/reply
- **Request**: “Кто имеет IP X? Ответьте с MAC Y”
- **Reply**: конкретный MAC-адрес для IP X

## Почему ARP — первая “дыра”
- ARP не аутентифицирован: можно подменять соответствия.
- ARP spoofing / poisoning:
  - атакующий отправляет ложные ARP reply
  - жертва начинает слать трафик атакующему (Man-in-the-Middle)
- Типичные эффекты:
  - перехват трафика
  - подмена шлюза (если отравить ARP шлюза)
  - перехват логинов/данных без шифрования.

## Защита (базово)
- Сегментация сети (VLAN)
- статические ARP (в малых средах)
- DHCP snooping / Dynamic ARP Inspection (если поддерживается)
- шифрование выше (TLS/SSH) — снижает ущерб от MITM
