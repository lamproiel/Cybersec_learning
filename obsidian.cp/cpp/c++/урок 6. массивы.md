
# одномерные массивы

Массивы данных можно представлять как обычные переменные, но в переменной можно хранить лишь одно единственное значение, а в массиве можно хранить сразу набор из нескольких значений.

с массивами идет тот же принцип работы, что и с переменными, т.е. можно добавлять значения, выводить значения на экран, менять их и т.д.

при создании массива прописываем примерно точно ту же самую конструкцию, как и при создании обычной переменной. т.е.
	1. указать тип данных
	2. указать название массива 
	3. чтоб это был массив, после названия нужно установить `[] и указать в них число` - это то кол-во элементов, которое будет находиться внутри самого массива 
```cpp
int nums [3]; //массив, который будет состоять из 3 элементов (сейчас пустые, не имеют значения)
```


можно установить значения, обращаясь к массиву и в `[]` указать индекс элемента (индекс к которому надо обратиться), он начинается с 0
```cpp
int nums [3]; //отчет идет с 0
nums[0] = 56;
nums[1] = 563;
nums[2] = 2;

nums [1] = 4;
nums [1]++;    //можно менять, увеличивать элемент и т.д.

	std::cout << nums [1]; //т.е. разница с переменными в том, что нужно указывать индекс
```



но все эти значения можно присваивать сразу же при создании массива
```cpp
float nums2[3] = {4, 6, 7}; //тот же массив, но все значения сразу установлены
```


можно установить значения для всех переменных, так и только для нескольких первых элементов, т.е.
```c++
float nums2[3] = {4, 6}; //т.е. установлены значения только для первых 2 элементов, а 3 без установленного значения
```


нельзя только установить значения для элемента, который изначально не был описан в массиве. 

если же указать много лишних элементов в массиве, то будет занято много оперативной памяти и код будет не оптимизирован.

это и есть базовый функционал по работе с массивами, можно
	1. создавать
	2. присваивать значения для каждого из элементов
	3. элементы можно менять, выводить на экран, проделывать мат. операции с элементами, использовать внутри условий, циклов и т.д.



если надо вывести много элементов на экран, то можно сделать это с помощью цикла: 
```cpp
float nums2[3] {4, 6, 7};

for (int i = 0; i < 3; i++) { 
	std::cout << "El " << i << ": " << nums2[i] << endl;  // i это переменная которая будет идти от 0 до 3 не включительно
}
```


## практический пример

### первая программа

программа, где мы запрашиваем у пользователя разные значения, и эти значения будем подставлять в качестве значений для самого массива.
```cpp
using namespace std;

float numbers[5];  //создали массив 
for (int i = 0; i < 5; i++) {  //создали цикл (пройдется от 0 до 5 не вкл.)
	cout << "Enter number " << i << ": ";  //вывод сообщ.
	cin >> numbers[i];  // получаем значение от пользователя
```

### вторая програма

программа, за счет которой мы подсчитаем сумму всех элементов, что будет внутри массива 
```cpp
using namespace std;

float numbers[5];
for (int i = 0; i < 5; i++) {
	cout << "Enter number " << i << ": ";
	cin >> numbers[i];
	
float summa = 0;
for (int i = 0; i < 5; i++) {
	summa += numbers[i];
}
cout << "Summa: " << summa << endl;  //т.е. перебираем весь массив и каждый элемент, его значение добавляем к переменной summa, тем самым мы и получим сумму всех элементов
```


научимся находить минимальный элемент внутри массива:
```cpp
using namespace std;

float numbers[5];
for (int i = 0; i < 5; i++) {
	cout << "Enter number " << i << ": ";
	cin >> numbers[i];
	
float summa = 0;
float min = numbers[0];  //пусть минимальный элемент = первый элемент массива, даже если это не так, то внутри цикла это можно проверить, и если будет какой-то новый минимальный элемент, то его можно перезаписать

for (int i = 0; i < 5; i++) {
	summa += numbers[i];
	if(numbers[i] < min)
		min = numbers[1];  //если текущий элемент меньше чем минимальный элемент, значит мин. элемент становится текущим элементом
}
cout << "Summa: " << summa << endl;
cout << "Min: " << min << endl;  //вывод мин. элемента
```

# многомерные массивы

многомерные массивы отличаются тем, что в одномерных массивах каждый элемент - конечное значение (3, 5, 10), в многомерных массивах каждый элемент это еще какой-либо массив

создадим двумерный массив, т.е. каждый элемент 1 массива является еще каким-либо массивом.
```cpp
using namespace std;

int matrix[3][2] = {
	{3,5},  //первый массив, состоящий из еще каких либо массивов и тд
	{5, 8},
	{-2, 0}
};  //каждый массив будет состоять из 2 элементов

	cout << matrix[1][1] << endl;  //вывод на экран 2 массива 2 элемента
```
также можно устанавливать новые значения для элемента, проводить мат. операции и тд

вывод всех элементов такого двумерного массива через цикл:
```cpp
using namespace std;

int matrix[3][2] = {
	{3,5}, 
	{5, 8},
	{-2, 0}
};
for (int i = 0; i < 3; i++) {
	for (int j = 0; j < 2; j++) {
		cout << matrix[i][j] << endl;
	}
}
```
