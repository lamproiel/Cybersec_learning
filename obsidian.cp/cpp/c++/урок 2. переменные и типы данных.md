# 1. использование переменных в C++

## Что такое переменная

Переменная — это именованная область памяти (ячейка в памяти пк), в которой хранится значение.

В программе используются две целочисленные переменные:
```cpp
int a, b;
```
- `int` — тип целого числа;
- `a` и `b` — имена переменных;
- значения переменных можно изменять во время выполнения программы.

например:
```cpp
#include <iostream>

int main() {
    int a, b;

    std::cout << "Введите переменную a: ";
    std::cin >> a;

    std::cout << "Введите переменную b: ";
    std::cin >> b;

    std::cout << "A: " << a << ". B: " << b;

    return 0;
}
```

Объявление переменных
```cpp
int a, b;
```
Или сразу присвоить начальные значения:

```cpp
int a = 0;
int b = 0;
```
## Ввод значения

```cpp
std::cin >> a;
```

`std::cin` получает данные с клавиатуры.

Оператор `>>` записывает введённое значение в переменную `a`.

Например, если пользователь введёт:

```text
15
```

то переменная `a` получит значение `15`.

## Ввод второй переменной

```cpp
std::cout << "Введите переменную b: ";
std::cin >> b;
```

Эти строки выводят приглашение и записывают введённое пользователем число в переменную `b`.

## Вывод значений

```cpp
std::cout << "A: " << a << ". B: " << b;
```

Эта команда выводит текст и значения переменных.

Если пользователь ввёл:

```text
a = 10
b = 20
```

результат будет:

```text
A: 10. B: 20
```

Текстовые части заключаются в двойные кавычки:

```cpp
"A: "
". B: "
```

А имена переменных пишутся без кавычек:

```cpp
a
b
```

## Схема работы программы

```text
1. Объявить переменные a и b.
2. Попросить пользователя ввести a.
3. Сохранить введённое значение в a.
4. Попросить пользователя ввести b.
5. Сохранить введённое значение в b.
6. Вывести значения a и b.
```

## Важные правила

### Имена переменных

Имя переменной может содержать:

- латинские буквы;
- цифры;
- символ подчёркивания `_`.

Имя не должно начинаться с цифры.

Корректные имена:

```cpp
int age;
int number1;
int user_score;
```

Некорректные имена:

```cpp
int 1number;
int user-score;
```

C++ различает регистр:

```cpp
int age;
int Age;
```

`age` и `Age` — разные переменные.

### Точка с запятой

Большинство инструкций C++ заканчиваются точкой с запятой:

```cpp
int a, b;
std::cin >> a;
std::cin >> b;
```
## Краткий итог

- `int a, b;` объявляет две целочисленные переменные.
- `std::cin >> a;` считывает значение в `a`.
- `std::cin >> b;` считывает значение в `b`.
- `std::cout << a;` выводит значение `a`.
- Переменные хранят данные, с которыми программа может работать.
- `std::cout` используется для вывода, а `std::cin` — для ввода.


# 2. типы данных

# Типы данных в C++

Тип данных определяет:

- какие значения может хранить переменная;
- сколько памяти она занимает;
- какие операции над ней можно выполнять.

Пример:

```cpp
int number = 5;
```

Здесь:

- `int` — тип данных;
- `number` — имя переменной;
- `5` — значение переменной.

## Целочисленные типы

Целочисленные типы используются для хранения чисел без дробной части.

```cpp
short num1 = 7;
int num2 = 5;
long num3 = 9;
```

| Тип | Назначение |
|---|---|
| `short` | небольшие целые числа |
| `int` | основной тип для целых чисел |
| `long` | целые числа большего диапазона |

- `short` — не менее 2 байт;
- `int` — не менее 2 байт;
- `long` — не менее 4 байт.

На распространённых системах:

| Тип | Windows 64-bit | Linux 64-bit |
|---|---:|---:|
| `short` | 2 байта | 2 байта |
| `int` | 4 байта | 4 байта |
| `long` | 4 байта | 8 байт |
| `long long` | 8 байт | 8 байт |

## Знаковые типы

Обычные целочисленные типы могут хранить положительные и отрицательные значения:

```cpp
short num1 = -7;
int num2 = 5;
long num3 = -100000;
```

Диапазон зависит от размера типа.

Для типа размером 4 байта приблизительный диапазон:

```text
от -2 147 483 648 до 2 147 483 647
```
## Беззнаковые типы

Ключевое слово `unsigned` запрещает хранить отрицательные значения:

```cpp
unsigned short num4 = 7;
unsigned int num5 = 5;
unsigned long num6 = 9;
```

Все доступные значения используются для положительного диапазона.

Например, для 4-байтового `unsigned int` диапазон обычно выглядит так:

```text
от 0 до 4 294 967 295
```

Пример:

```cpp
unsigned int age = 25;
```

Беззнаковые типы полезны, когда отрицательные значения невозможны: для количества объектов, размеров, индексов и битовых масок.

## Числа с плавающей точкой

Для хранения дробных чисел используются `float`, `double` и `long double`.

```cpp
float num7 = 56.426246f;
double num8 = 353.46145151;
long double num9 = 353.46145151L;
```

### `float`

```cpp
float number = 3.14f;
```

- обычно занимает 4 байта;
- имеет меньшую точность;
- используется, когда важен небольшой размер данных.

Суффикс `f` означает, что число является литералом типа `float`.

### `double`

```cpp
double number = 3.141592653589793;
```

- обычно занимает 8 байт;
- имеет большую точность, чем `float`;
- является стандартным выбором для дробных вычислений.

В исходном примере:

```cpp
double num8 = 353.46145151f;
```

суффикс `f` создаёт сначала значение типа `float`, а затем оно преобразуется в `double`. Лучше записать:

```cpp
double num8 = 353.46145151;
```

## Тип `char`

Тип `char` используется для хранения одного символа:

```cpp
char sym = '&';
```

Вывод:

```cpp
#include <iostream>

int main() {
    char symbol = '&';

    std::cout << symbol << '\n';

    return 0;
}
```

Результат:

```text
&
```

Символ записывается в одинарных кавычках:

```cpp
char letter = 'A';
```

## Тип `bool`

Тип `bool` хранит только два значения:

```cpp
true
false
```

Пример:

```cpp
bool isHappy = true;
bool isReady = false;
```

Обычно `bool` используется в условиях:

```cpp
int age = 20;
bool isAdult = age >= 18;

if (isAdult) {
    std::cout << "Совершеннолетний";
}
```
## Краткая таблица

| Тип            | Пример                        | Назначение                        |
| -------------- | ----------------------------- | --------------------------------- |
| `short`        | `short a = 7;`                | небольшие целые числа             |
| `int`          | `int a = 5;`                  | обычные целые числа               |
| `long`         | `long a = 9;`                 | целые числа большего диапазона    |
| `long long`    | `long long a = 9000000000LL;` | большие целые числа               |
| `unsigned int` | `unsigned int a = 5;`         | неотрицательные целые числа       |
| `float`        | `float a = 3.14f;`            | дробные числа с меньшей точностью |
| `double`       | `double a = 3.14;`            | дробные числа с большей точностью |
| `char`         | `char a = 'A';`               | один символ                       |
| `bool`         | `bool a = true;`              | логическое значение               |
