При помощи условной конструкции можно прописать некое условие и взависимости если это условие будет верным, то выполнить один кусочек кода, а если условие окажется неверным, то выполнить другой кусочек кода.

# if

Конструкция для условий:
```c++
  if(5 > 3) { 
  
  }  
```
 - если 5 > 3 то, будет выполен код внутри фигурных скобок. 

пример:
```c++
int num
std::cout << "Введите число: ";
std::cin >> num;

if (num > 3) {
	std::cout << "Число больше 3"
}
```
- если переменная `num` больше чем 3, то выполняется код в {}
- если число будет <3, то ничего не выполняется, т.к. условие не было выполнено.

в `if()` можно ставить `>` `<` `==` 
- просто `=` считалось бы запись числа в переменную.

для проверки на неравенство используется !=
- пример: `if (num != 3) {}` 
  - т.е. если переменная `num` не равна числу `3`, то код будет обработан
  - а если переменная `num` равна числу 3, то код не будет обработан.

также можно использовать >= ,  =< 

внутри `if () {}` можно описать сколько угодно строчек кода,
  кроме того внутри можно описать еще одно условие, т.е.
  ```c++
  int num;
  std::cout << "Введите число: ";
  std::cin >> num;
  
  if (num =3) {
	  std::cout << "Число больше 3 ";
	  std::cout << "Число больше 3 ";
	  if (num == 5) {
		  std::cout << "Число = 5 ";
	  }
  }
  ```
 - т.е. если число, которое ввел пользователь > `3`, то условие срабатывает
	- выводится текст `Число больше 3 `
- срабатывает след. условие, т.е. если пользователь ввел `num = 5`, то 
	- выводится текст `Число равно = 5 `.

# else

```c++
int num;
std::cout << "Введите число: "
std::cin >> num;

if (num > 3) {
	std::cout << "Число больше 3 ";
	if (num == 5) {
	std::cout << "Число == 5 ";
	}
}
else {
	std::cout << "сработал else";
}
```

все, что будет прописано внутри `else {}`, будет срабатывать каждый раз, если вдруг основное условие оказалось неверным.
  - т.е. если `num = 4`, то условие `if {}` не  выполняется, 
  - а выполняется условие внутри `else {}`
	  - выводится `сработал else`.

`else` прописывается только в паре с оператором `if`.

# else if

можно дописывать доп. условие `else if` по необходимости.
  всегда прописывается после основного `if` и до `else`.

`else if` можно прописывать сколько угодно.
```c++
int num;
std::cout <<  "Введите число: "
std::cin >> num;

if (num > 3) {
	std::cout << "Число больше 3 ";
	if (num == 5) {
	std::cout << "Число == 5 ";
	}
}
else if (num == 2 ) {
	std::cout << "Число = 2" << std::endl;
}
else if (num == -1) {
	std::cout << "Число = -1";
}
```
- если ввести число `-1` , 
	- то на экран выведится `Число = -1`

- т.е. если мы ввели `-1`, то программа проверила условие `if (num > 3) {}` и оно оказалось неверым,
	- поэтому перешла на проверку условием `else if`
	  - программа проверила условие `else if (num == 2)` и оно оказалось неверным, 
	  - поэтому программа перешла на  след. проверку условия `else if (num == -1)` и оно оказалось верным,
		  - поэтому программа выводит `Число = -1`.
## важный момент

если внутри кода `else if () {}`или `else () {}`  только одна строчка кода, то `{}` можно не ставить, т.е.
```c++
int num;
std::cout << "Введите число: ";
std::cin >> num;

if (num > 3) {
	std::cout << "Число больше 3 ";
	if (num == 5)
		std::cout << "Число == 5 ";
}
else if (num == 2 )
	std::cout << "Число = 2" << std::endl;
else if (num == -1)
	std::cout << "Число = -1";
else
	std::cout << "сработал else";
```
- если внутри условия несколько строчек кода, то `{}` обязательны.

## проверяем сразу несколько условий

### оператор - или (`||`)
```c++
int num;
std::cout << "Введите число: ";
std::cin >> num;

bool i_h_c = true;

if (num > 3 || i_h_c == true) {
	std::cout << "Число больше 3 ";
	if (num == 5)
		std::cout << "Число == 5 ";
}
else if (num == 2 )
	std::cout << "Число = 2" << std::endl;
```
условие `if` сработает, если условие =
- `num > 3` ИЛИ `i_h_c == true`
	- `||` обозначает ИЛИ.
- т.е. либо первое условие `num > 3` должно быть верным, либо второе условие `i_h_c == true` должно быть верным
	- и тогда код внутри `if` сработает. 

### оператор - и (`&&`)
```c++
int num;
std::cout << "Введите число: ";
std::cin >> num;

bool i_h_c = true;

if (num > 3 && i_h_c == true) {
	std::cout << "Число больше 3 ";
	if (num == 5)
		std::cout << "Число == 5 ";
}
else if (num == 2 )
	std::cout << "Число = 2" << std::endl;
```
условие `if` сработает, если условие =
- `num > 3` И `i_h_c == true`
	- `&&` обозначает И.
- т.е. и первое условие `num > 3` должно быть верным, и второе условие `i_h_c == true` должно быть верным.
	- и тогда код внутри `if` сработает.

т.е. в любом операторе `if` и `else if` можно прописывать сколько угодно доп. условий и объединять их за счет условных операторов `||` или `&&`.

### проверка bool переменных
```c++
int num;
std::cout << "Введите число: ";
std::cin >> num;

bool i_h_c = true;

if (num > 3 && i_h_c) {
}
```
можно сокращать bool переменные:
- вместо `i_h_c == true` можно сокращать до названия самой переменной:
	- `i_h_c` т.е. и так проверяется на значение true.

либо же если надо чтобы было `i_h_c == false`, то можно сокращать вместе с `!`:
- вместо `i_h_c == false` до
	- `!i_h_c` т.е. проверяется на значение false из за `!` в начале.

## switch case

за счет этой конструкции мы можем проверять лишь одну какую-либо переменную на несколько возможных ее значений. 
```c++
int num;
std::cin >> num;

switch (num) {
	case 5:
		std::cout << "Num is 5";
		break;
	case 50:
		std::cout << "Num is 50";
		break;
}
```
условие `switch` для проверки переменной `num` на несколько ее возможных значений.
- можно проверять только одну переменную
- `case` различные варианты совпадений

т.е. если `num` будет = `case 5:` (числу 5), то
- выведется `Num is 5`
если `num` будет = `case 50:` (числу 5), то
- выведется `Hum is 50`
	- подобных условий можно записать сколько угодно.

в конце каждого `case` необходимо дописывать `break;`
- за счет него на этом этапе тело условия будет завершено.

внутри `case break` можно прописывать сколько угодно строк кода, и все эти строчки кода будут выполняться, если `num` будет равна числу `5`.

в switch case можно проверять только точное совпадение (нельзя `>`,`<` и т.д.)

обычно switch case использует, когда какая-либо переменная может принимать несколько вариантов значений.

## доп. оператор default

если все пред. case оказываются неверными, то по умолчанию сработает `default` (как else).
```c++
int num;
std::cin >> num;

switch (num) {
	case 5:
		std::cout << "Num is 5";
		break;
	case 50:
		std::cout << "Num is 50";
		break;
	default:
		std::coit << "Default";
		break;
}
```
внутри `default` можно использовать условия, создавать переменные и т.д.

т.е. если все `case` не подойдут, то
- сработает `default`.
