
циклы - конструкции, за счет которых можно выполнять код несколько раз подряд, и кол-во повторений можно указывать сколько угодно самому.

## for 

в `for` указываем все условия сразу.
```cpp
for (int i = 0; i < 10; i++) {  //условия можно менять как угодно
	std::cout << "El: " << i << std::endl;
} 
```
`int i = 0;` переменная `i`;
`i < 10;` цикл будет работать, пока переменная i меньше чем число 10;
`i++` каким образом переменная `i` будет меняться, т.е.
	за каждый круг цикла будет увеличиваться на 1.
т.е. переменная идет 0 до 10 и за один круг переменная меняется на 1.

```cpp
for (int i = 100; i >= 10; i -=15) {
	cout << "El: " << i << std::endl;
}
```
т.е. каждый цикл будет отниматься -15, пока не будет больше или равно 10.

внутри цикла `for` можно прописать сколько угодно строчек кода.
	и если в цикле `for` только одна строчка кода, то `{}` ставить не обязательно.

удобен когда все условия нужно описать в одном едином месте
## while

разница между циклом  `for` в способе их написания.
	в цикле `for` прописываем все условия внутри `()`;
	а в цикле `while` только 1 параметр внутри `()`.
		пока условие корректно цикл выполняется, как только условие перестает быть корректным, то цикл не выполняется.

```cpp
int j = 0;
while(j < 10) {
	std::cout << "El: " << j << std::endl; 
	j++;
}
```
переменную создаем вне цикла,
прописываем только 1 условие внутри `while(...)`.

```cpp
float j = 100;
while(j > 60) {
	std::cout << "El: " << j << std::endl;
	j /= 1.5f;
}
```

удобен в том случае, когда есть только условие, и пока это условие верно, нужно чтобы цикл выполнялся
## do while

разница между `while` в том, что `do while` изначально один раз 100% сработает,
	потом проверит условие, 
		если оно будет корретным, то сработает,
		если условие окажется неккоретным, то не сработает.
```cpp
int k = 100;
do {
cout << "3. El: " << k << endl;
k -= 10;
} while  (k < 10);
```
условие изначально неверное, ведь `k` уже больше чем 10, т.е.
	цикл сработает 1 раз (выведет 100), потом проверит условие
		если оно верное, то продолжит работу
		если неверное, то больше не будет работать

удобен когда нужно изначально попробовать выполнить код, и дальше если условие окажется верным, то выполнять дальше, если неверным, то невыполнять.

## операторы внутри циклов

можно использовать в любом типе цикла

### break;

```cpp
for(int i = 1; i <= 15; i++) {
	if(i == 10)
	break;
	
	cout << "4. El: " << i << endl;
}
```
если мы доходим до числа 10, то выходим из цикла(выполняется оператор `break;` и как только он выполнится, программа полностью выйдет из этого цикла и продолжит дальнейшее выполнение).

### continue;

```cpp
for(int i = 1; i <= 15; i++) {
	if(i == 10)
	break;
	if (i % 2 == 0)
		continue;
	
	cout << "4. El: " << i << endl;
}
```
разница  с break в том, что можно пропустить один круг цилка

получаем остаток при делении на 2, и если остаток равен 0, то это четное число, 
	и в таком случае используется оператор `contunue;`, т.е он не выполняет дальнейший код, а сразу создает новый круг 

## практический пример

необходимо случайное число, которое будет выбрано самим компьютером

```cpp
srand(time(NULL));
int rand_num = 1 + rand() % 15; //создание рандомного числа
bool stop = false;
int user_input;
  
do {
	cout << "Enter number: ";
	cin >> user_input;
	if (user_input != rand_num)
		cout << "Вы не угадали" << endl;
	else
		stop = true;
} while (!stop); //цикл будет выполняться до тех пор, пока stop идет со значением false

cout << "Вы угадали";
```
мини игра где надо угадывать число, т.е.
	1. спрашиваем у пользователя число
	2. если он не угадывает (`user input не равен числу rand_num`), то 
		1. в таком случае переменная `stop` не меняется, условие оказывается неверным и мы повторно заходим внутрь этого цикла
		2. если пользователь угадывает, то условие оказывается неверным, срабатывает `else`, меняется значение переменной `stop`, условие больше оказывается неверным и в цикл больше не заходим, выводится "Вы угадали"

### пример с while
```cpp
srand(time(NULL));
int rand1 = 1 + rand() % 10;
int user;
	cout << "Введите число: ";
	cin >> user;

while (user != rand1) {
	cout << "Вы не угадали" << endl;

	cout << "Введите число: ";
	cin >> user;
}
cout << "Вы угадали";
```
