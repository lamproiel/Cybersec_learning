
тип данных string, который можно сразу записать в строку или целый текст. 

## пример в языке c

создание строки способом, который был использован в языке c :
```cpp
char word[] = {'H', 'I', '!'};  //когда вы сразу присваиваете элементы, то можно не указывать значение в самом массиве, кол-во элементов будет подставлено автоматически, в зависимости от того, сколько элементов вы пропишите.
for (int i = 0; i < 3; i++)
	cout << word[i];  //вывод каждого элемента из этого массива

```
- в языке c это был единственный способ описать строку, текст и т.д.

## пример в языке с++ 

пример с отдельным типом данным string, с ним можно намного проще описывать различные строки

чтобы работать с этим типом данных, изначально нужно подключить через 
`#include <string>`

```cpp
#include <string>  //подключение директивы 

std::string words = "Hello World!";  //создание переменной, используя тип string. (значение обязательно в " " )
std::cout << "\n" << words;  //вывод на экран и перевод на новую строку
```
- в значение переменной можно помещать много слов или целый текст, также можно писать на кириллице (с подкл. кодировки `setlocale(LC_ALL, "RU")` ).

## упрощенный пример в языке c

```cpp
char word[] = {"Hi!"};  //каждый символ слова будет отдельный элемент всего массива
```

## примеры работы со строками

любая строка это массив и к любому элементу этого массива можно обратиться и с любым этим элементов можно работать:
```cpp
#include <string>

string words = "Hello World!";
words[0] = 'W';  //обращение к 0 индексу (H), установить значение (символ помещать в ' ' ).
cout << "\n" << words;  //выведется Weelo World! 
```
  
## способ, за счет которого можно получить отдельную строку от пользователя

### как в языке c++
```cpp
string words;
cin >> words;
cout << "New: " << words; 
```  

в современных реалиях используется язык с++ и тип данных string.
