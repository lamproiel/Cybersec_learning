
## Что такое DNS
- Система соответствий:
  - доменное имя → IP адрес (и другие записи)
- Использует иерархию: root → TLD → authoritative → рекурсоры.

## Основные типы записей
- **A**: имя → IPv4
- **AAAA**: имя → IPv6
- **CNAME**: алиас → другое имя
- **MX**: серверы почты
- **NS**: чьи серверы authoritative
- **TXT**: произвольные текстовые (часто для верификаций)
- **SRV**: сервисы по домену и портам

## Как происходит резолв (идея)
1) Клиент спрашивает у рекурсора: “дай IP для example.com”.
2) Если у рекурсора кеш есть — отдаёт.
3) Если нет — рекурсор идёт по иерархии (или использует кеш/forwarders).
4) Ответ кэшируется с TTL.

## Почему DNS — частый вектор атак
- Если злоумышленник может:
  - подменить ответ DNS (spoofing/poisoning)
  - или перехватить трафик до резолвера
  - или скомпрометировать рекурсор/кэш
- тогда доменное имя может резолвиться в IP атакующего → MITM/фишинг.

## Типовые угрозы
- DNS spoofing / cache poisoning
- DNS hijacking (перехват DNS запросов на уровне сети)
- Риск при отсутствии TLS/защиты данных выше.

## Смежное
- DNSSEC уменьшает риск подмены через подписи (не устраняет все проблемы).
- DoT/DoH — защищают канал между клиентом и резолвером (уменьшают перехват/подмену по пути).
