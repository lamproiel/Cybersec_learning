
## IPv4
- Адрес: 32 бита.
- Обычно в виде 4 октетов: A.B.C.D.
- Пример: 192.168.1.10

## CIDR
- Формат: `IP/префикс`
- `префикс` = сколько старших бит занято сетью.
- Остальные биты = хосты внутри сети.

## Размер сети
- Кол-во адресов в сети: `2^(32 - prefix)`
- Кол-во **используемых** (для классической логики):  
  `2^(32 - prefix) - 2` (адрес сети и broadcast), если применяешь “классически”.

## Определение сети и диапазона (без калькулятора)
Шаблон:
- Для /24: шаг 256 в последнем октете → сеть меняется по 1-му “последнему” октету.
- Для /16: шаг 256 в двух последних октетах.
- Для /8: шаг 256 в трех последних октетах.

Пример логики:
- `192.168.10.0/24`  
  - сеть: `192.168.10.0`
  - broadcast: `192.168.10.255`
  - диапазон хостов: `192.168.10.1 ... 192.168.10.254`

## Почему это важно
- Правильно подобрать подсеть для маршрутизации и firewall.
- Понимать, почему “похожий” адрес может не попасть в одну сеть.
