
## NAT (Network Address Translation)
- Перевод адресов:
  - внутренние приватные IP → внешние публичные IP роутера
- Роутер меняет IP заголовков пакета по правилам.

## PAT (Port Address Translation) / NAPT
- На одном внешнем IP можно обслужить много внутренних хостов,
  различая соединения по портам.
- Практически это “NAT с портами”.

## Как это работает по сути (упрощённо)
1) Внутренний клиент: src = (IP_in, port_in) → dst = (IP_out, port_out)
2) Роутер выбирает внешний порт port_outside:
   - заменяет src IP на IP_public
   - заменяет src порт на уникальный внешний порт
3) Таблица NAT:
   - хранит соответствия, чтобы потом правильно вернуть ответы.

## Почему это важно
- У тебя много устройств в LAN, а внешний интернет требует уникальность адресов.
- Это позволяет использовать private range (RFC1918).

## Типичные виды NAT
- SNAT: “наружу” (часто для исходящего трафика)
- DNAT: “внутрь” (проброс портов/публикация серверов)
- Port forwarding — частный случай DNAT + PAT.

## Ограничения/нюансы
- Нет end-to-end “прямой” адресности без поддержки маршрутизации.
- Хуже для некоторых протоколов, особенно нетипичных (нужно ALGs или правильная конфигурация).
